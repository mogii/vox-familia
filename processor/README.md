# 视频 → 成品图（全程本地）

对着摄像头一件件介绍宝宝闲置，说「**下一件**」切换下一样；想查新品参考价就说「**查原价**」。
录完在自己电脑上跑两步，就能得到一张张**可直接发微信群的成品图**（照片 + 价格 + 原价 + 描述）。

1. `process.py` — 视频转文字、按「下一件」切段、每件挑几张最清楚的图、用大模型听出
   最终价格(美元)写好标题描述、（说了「查原价」的）联网搜新品参考价 → 输出 `out/`。
2. `webapp.py` — 本地网页：每件挑用哪几张图、改标题/价格/原价/描述、给每张图加一句话，
   一键把多张图**合并成一张长图**存到 `out/posts/`，你下载发群。

语音转文字用本地 Whisper，**视频不会离开你电脑**；只有每件的口述文字会发给大模型整理，
说了「查原价」的那件会联网搜一次。

## 装环境（一次性）

```bash
cd processor
python3 -m venv .venv && source .venv/bin/activate   # 可选，但推荐
pip install -r requirements.txt
cp .env.example .env        # 然后编辑 .env 填上你的 key 等
```

`requirements.txt` 里的 `imageio-ffmpeg` 自带 ffmpeg，不用单独装。第一次跑 Whisper 会
自动下载模型（`small` 约几百 MB），之后走本地缓存。成品图印中文用你 Mac 自带字体。

`.env` 里要填：

- `ANTHROPIC_API_KEY` — 大模型 key（提价格 / 写描述用，费用很小）。可用官方 Claude，
  也可用 **Moonshot/Kimi**：key 填这里，再把 `LLM_BASE_URL` 设为
  `https://api.moonshot.ai/anthropic`、`CLAUDE_MODEL` 设为 `kimi-k2.5`（见 `.env.example`）。
  「查原价」联网搜索用 Kimi 的 `$web_search`，默认复用同一把 Moonshot key。
- `CONTACT` — 你的微信号（留作 `listings.json` 里的参考字段）。

## 第一步：处理视频

```bash
python process.py 我的视频.mov     # .mov / .mp4 都行，iPhone 录的直接用
```

跑完得到一个 `out/` 目录：

```
out/
├── transcript.txt        全部转写文字（参考用）
├── listings.json         整理好的商品列表
├── item01/item01_1.jpg   第 1 件挑出来的几张图
├── item02/...
└── ...
```

常用参数：

- `--frames 6` 每件最多挑几张图（默认 5）
- `--fps 3` 抽帧采样频率，动作快可调高（默认 2）
- `--no-ai` 不调大模型，只切段+挑图（价格/描述留空，到网页里手填）
- `--no-market` 即使说了「查原价」也不联网搜

### 「查原价」查市场参考价

对想查价的那件多说一句「**查原价**」，脚本就联网搜它的**新品参考价**写进 listing。每件都记
`marketSearched`：`true`+`marketPrice:null` 表示「搜了但没搜到」，`false` 表示「没搜」——
区分得开。2019 这种老款未必有精确对应价，都当参考，到网页里能改能删。换暗号见 `.env` 的
`PRICE_TRIGGERS`。

## 第二步：网页里整理 + 生成成品图

```bash
python webapp.py            # 然后浏览器打开 http://127.0.0.1:5000
```

网页里每件可以：

- **挑图**：勾选这件要用哪几张（默认全选），点缩略图也能切换。
- **改字**：标题、价格、原价文本、成色、描述，直接改。
- **每张图加一句话**：比如某张写「侧面：卡扣完好」。
- 点右上角 **生成全部成品图**：每件合成一张长图（首图下方放基础信息白卡，其余选中的图
  各自带你写的那句话），存到 `out/posts/itemNN.jpg`，网页里能直接看、右键另存。

把 `out/posts/` 里的成品图一张张发到微信群即可。改完想留痕就先点「保存修改」，会写回
`listings.json`。

## 录视频的小建议

- 一件讲完了再说「下一件」，停顿半秒更好切；要查价就顺嘴说「查原价」。
- 价格说清楚；临时改主意也行，脚本取你**最后说定**的价。
- 想图更好看：每件多换几个角度、光线亮一点，脚本自动挑最清楚的。

## 暗号可以改

切段默认「下一件 / 下一个 / 下一样 / 下一款」，查价默认「查原价」。都能在 `.env` 里用
`TRIGGERS=` 和 `PRICE_TRIGGERS=`（逗号分隔）自定义。
